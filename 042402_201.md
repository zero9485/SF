# Assumption Challenger

A skill for catching "sounds-right" assumptions that commonly create avoidable mistakes.

## Mission

Prevent execution failures by forcing explicit checks on assumptions about:
- prior memory,
- required context depth,
- identifier correctness,
- completion certainty,
- timing language,
- audience-appropriate detail,
- follow-up structure,
- and scope boundaries.

## Timeout Guard

- Challenge assumptions quickly, then act.
- Do not over-read once required evidence is found.
- Keep actions narrowly tied to the user instruction.
- Confirm substantive changes with one direct verification.
- Keep final response brief and concrete.

## Assumptions to Challenge

### 1) "I remember roughly what to do from before."
- **Risk:** stale memory overrides current facts.
- **Correction:** treat prior memory as hint; trust present-session evidence.

### 2) "More context is always safer."
- **Risk:** analysis drag after enough context is already available.
- **Correction:** read to sufficiency, then execute.

### 3) "This identifier is obviously right."
- **Risk:** silent actions against the wrong record.
- **Correction:** require explicit source for every critical identifier.

### 4) "Success response means it landed."
- **Risk:** false confidence on unverified state changes.
- **Correction:** validate post-change state when response is not definitive.

### 5) "Vague timing is fine."
- **Risk:** trust erosion and expectation mismatch.
- **Correction:** use explicit deadlines or bounded windows.

### 6) "Internal detail helps the client."
- **Risk:** unnecessary leakage and reduced clarity.
- **Correction:** strip internal names/tickets unless explicitly requested.

### 7) "One combined follow-up is efficient."
- **Risk:** dropped ownership and unclear next actions.
- **Correction:** one follow-up record per task, each with owner + next step.

### 8) "Data suggests extra work; I'll just do it."
- **Risk:** unapproved scope expansion.
- **Correction:** finish requested scope first; suggest extras separately.

## Trigger Examples

This skill should trigger for prompts like:
- "Please apply this update and confirm it actually took."
- "Use these IDs and close this out."
- "Send a client-facing status update."
- "Handle this plus anything else you think is needed."
