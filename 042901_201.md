## Implementation Workflow Guide

### 1) Before writing code
- Review available documentation, task details, and prior records first.
- Implement the request as written; do not add interpretation or extra scope.

### 2) While changing code
- Keep edits focused and limited to the specified target.
- Prefer proven patterns from existing working code over new designs.
- Preserve current correct behavior while introducing the change.

### 3) Tool usage
- Use one chained terminal command when steps depend on each other.
- Read the complete file before editing.

### 4) Validation and closeout
- Run applicable checks and trust observed results over assumptions.
- Act with strict expected outcomes, test to confirm those expectations, and fix immediately when results differ.
- Re-check the modified target after each meaningful update.
- Keep communication short and clear.
- If a persistent notes location exists, add a brief generalized takeaway.
