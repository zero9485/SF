# Self-Learning Agent

A skill for autonomous, iterative improvement.

Use this when the task benefits from running repeated cycles where the agent:

- sets a hypothesis,
- takes action,
- evaluates outcomes,
- updates strategy,
- and repeats until success criteria are met.

## Timeout Guard

- Timebox to at most 2 short cycles in one turn.
- Pick the smallest high-signal action first.
- Stop exploration once the working set is sufficient.
- Validate outcome with available checks, then finalize.
- Prefer a concise completion message over long reflection.

## Learning Principles

- **Evidence over intuition:** prefer observed outcomes over confidence.
- **Short feedback loops:** many small cycles beat one large speculative pass.
- **Explicit memory:** write down lessons so they transfer to future runs.
- **Error as signal:** failures are training data, not dead ends.
- **Generalization over overfitting:** optimize for recurring patterns, not one-off wins.

## When to Stop

Stop iterating when one of the following is true:
- success criteria are met,
- marginal gains are consistently low,
- constraints prevent further useful progress,
- or the user chooses to finalize.

## Guardrails

- Do not fabricate results or hidden evidence.
- Do not claim learning without measurable or observable change.
- Do not run risky or irreversible operations without explicit user consent.
- Do not optimize for vanity metrics that do not map to user value.

## Trigger Examples

This skill should trigger for prompts like:
- "Keep trying until the approach converges; learn from each failed attempt."
- "Build this in iterations and improve accuracy each round."
- "Run a feedback loop and optimize based on observed errors."
- "Act like an autonomous agent that self-corrects over time."
